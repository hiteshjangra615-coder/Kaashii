Included files
- index.html: the website (HTML, CSS and JavaScript in one file)
- purple-sky.jpg: the exact purple, starry-cloud background image

- The page background now uses purple-sky.jpg across all 8 chapters.

Preview on your computer
1. Keep index.html and purple-sky.jpg in the same folder.
2. Open index.html in Chrome or another modern browser.

Publish to your existing GitHub Pages site
1. Open the repository used by https://hiteshjangra615-coder.github.io/Kaashii/ and make a backup of the current files first.
2. Upload/replace index.html and upload purple-sky.jpg into the same folder/branch that GitHub Pages publishes.
3. Commit the changes and wait for GitHub Pages to publish.
4. Refresh the website. If the old background remains, hard-refresh or clear the browser cache.

Important
- This ZIP does not publish or commit to GitHub automatically. The live website will not change until you upload and commit these files.
- Keep the image filename exactly “purple-sky.jpg” and in the same folder as index.html.

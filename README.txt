KAASHI — PREMIUM PURPLE GLASS WEBSITE
=====================================

Included files
- index.html: the website (HTML, CSS and JavaScript in one file)
- purple-sky.jpg: the selected purple starry-cloud background

Design
- Purple/lavender starry-cloud background across all 8 chapters.
- Translucent Premium Purple Glass panels so stars and clouds remain visible behind the cards.
- Soft lavender glow, pink-purple buttons, glass-style navigation and readable light text.
- No red moon and no added moon scene.
- Mobile-friendly layout and smooth transitions; reduced-motion preferences are respected.
- Existing chapter content, navigation and interactions are preserved, including Chapter 8 letter reveal/typing controls.

Preview
1. Keep index.html and purple-sky.jpg together in the same folder.
2. Open index.html in Chrome or another modern browser.

Publish to the existing GitHub Pages website
1. Open the repository used by https://hiteshjangra615-coder.github.io/Kaashii/ and back up the current files first.
2. Upload/replace index.html and upload purple-sky.jpg into the same folder/branch that GitHub Pages publishes.
3. Commit the changes and wait for GitHub Pages to publish.
4. Refresh the website. If the old version remains, try a hard refresh or clear the browser cache.

Important
This ZIP does not publish or commit to GitHub automatically. The live website changes only after you upload and commit these files. Keep the image filename exactly purple-sky.jpg and in the same folder as index.html.
